# SprintBoard Ops — Project Milestones & RAID Log

A clean Project Management & Operations web workspace for tracking milestones, owners, due dates, and a structured RAID log (Risks, Assumptions, Issues, Dependencies) with instant Markdown status report generation.

## Features
- **Milestone Tracker**: Track deliverables, owners, target dates, and completion status.
- **RAID Log**: Categorize Risks, Assumptions, Issues, and Dependencies by severity (`High`, `Medium`, `Low`).
- **One-Click Status Report**: Copies a formatted Markdown weekly status update directly to your clipboard.

## Quick Start
Open `index.html` in any browser.
